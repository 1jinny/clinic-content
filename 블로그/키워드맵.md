# 불당드림치과 키워드 맵

새 글을 쓰기 전에 이 표부터 확인합니다. **포커스 키워드가 이미 있으면 그 키워드로 새 글을 쓰지 않습니다.**

## 규칙

1. **한 글 = 포커스 키워드 1개 = 검색 의도 1개.** 같은 포커스 키워드는 사이트 전체에서 한 번만 씁니다.
2. **검색 의도로 나눕니다.** 같은 주제라도 의도가 다르면 다른 글입니다.
   원인·증상 / 비용·기간 / 방법 선택 / 대상(나이·상황) / 관리·예방
3. **헤드 키워드는 블로그에 쓰지 않습니다.** `불당동 치과`, `천안 치과`, `신불당 치과`는 홈·서비스 페이지 몫입니다. 블로그는 이 페이지로 **링크만** 보냅니다.
4. **클러스터 구조로 묶습니다.** 허브(총정리) 1개 + 스포크(세부 글) 여러 개. 스포크는 허브로, 허브는 스포크로 링크합니다.
5. 링크 문구는 "자세히 보기"가 아니라 **도착 페이지의 제목이나 키워드**로 씁니다.
6. 네이버 블로그에 같은 주제를 올릴 때는 구어·질문형 키워드로 **문장과 구조를 전부 새로** 씁니다.

> 기존 글 목록은 본문 이미지 파일명으로 추정한 것입니다(⚠ 추정). Rank Math에서 실제 포커스 키워드를 확인해 이 표를 고쳐 주세요.
